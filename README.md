## 🚀 ДЕПЛОЙ НА VERCEL ЗА 1 ХВИЛИНУ (DRAG & DROP)

Папка `deploy_vercel` є **100% статичною** (HTML5, CSS3, Vanilla JS):
1. Відкрийте браузер і перейдіть на [vercel.com/new](https://vercel.com/new).
2. **Просто перетягніть мишкою всю папку `deploy_vercel`** у вікно браузера (область Drag and Drop).
3. Натисніть кнопку **Deploy**.
4. За 5 секунд ваш сайт опубліковано онлайн на безкоштовному CDN із HTTPS без жодних збірок чи помилок!

## 💎 ОСОБЛИВОСТІ НОВОГО ДИЗАЙНУ ТА UX

1. **Епічний Hero-блок:**
   - Преміальна Bento-вітрина з 3 реальних фотографій акційних наборів (`set-large.jpg`, `set-apple.jpg`, `set-peach.jpg`).
   - Скляна картка довіри з круглим логотипом `logo.png` та чіткою статистикою: **20+ років досвіду**, **23.5k TikTok**, **106k вподобань**.
   - Глибокий градієнт `#0D2B1A -> #164429 -> #0F311E` із м'яким радіальним світловим акцентом.
   - Сміливий H1 заголовок `clamp(2.3rem, 4.4vw, 3.5rem)`.
2. **Картки каталогу (3 просторі колонки на десктопі):**
   - Верхня кольорова лінія-акцент 4px за культурами (рубінова, янтарна, сливова, смарагдова, теракотова).
   - Крупний заголовок сорту `1.35rem` та легкий для читання опис `1rem`.
   - Дворядовий надійний нижній блок: контрастна ціна `150 грн` + `за 1 саджанець`, нижче — степпер `[ − 1 + ]` (46px) та кнопка «В кошик» (46px). Жодних зламаних переносів.
   - Акційні набори виключено із загальної вкладки «Всі саджанці», вони доступні окремо у вкладці «🔥 Акційні набори».
   - Індикатор **«✓ Вже у кошику: N шт.»** підсвічує додані позиції.
3. **Блок стандартів розплідника:**
   - Чисті, стильні inline SVG-іконки у кружечках 56x56px замість системних емодзі.
4. **Повна оптимізація під Apple iPhone (iOS Safari):**
   - Кнопка `🔍 Збільшити` на банерах наборів перенесена в правий нижній кут.
   - Підтримка Safe Area (`env(safe-area-inset-bottom)`).
   - Нативний **iOS Bottom Sheet** для кошика та замовлення.
   - Зони натискання >= 44x44px.
   - Плаваюча кнопка «↑ Вгору».
